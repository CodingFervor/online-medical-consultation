# Online Medical Consultation Platform

## English | [中文](#中文)

An online medical consultation (telemedicine) platform built with Go, Gin, PostgreSQL, and Redis.

### Features
- Online video/text consultation
- Doctor scheduling and availability
- Patient health records
- E-prescription management
- Medical image upload and review
- Appointment booking and management
- Payment and billing
- Drug information and interaction check
- Patient-doctor matching
- Follow-up management

### Quick Start
```bash
docker-compose up -d
go run cmd/api/main.go
```

基于 Go + Gin + PostgreSQL + Redis 构建的在线医疗问诊（远程医疗）平台。

### 功能特性
- 在线视频/图文问诊

- 预约挂号和管理
- 支付和账单
- 药品信息和相互作用检查
- 医患匹配
